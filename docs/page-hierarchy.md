# 页面与右滑返回

手机、手表的路由层级：

- 会话列表是根页，右滑不会退出网站。
- 菜单从当前页面上方打开。菜单打开联系人或“我的”时，保留菜单在底下。
- 联系人、“我的”返回会话列表；从菜单进入时，先露出仍在底下的菜单。
- 聊天记录进入来源是会话列表、联系人或“我的”，返回到实际来源。
- 会话信息返回聊天，音频播放器返回会话信息。
- 设置覆盖菜单，视觉效果覆盖设置。
- 我的贴纸 → 贴纸包 → 媒体查看器逐层覆盖。关闭子层不关闭父层；发送贴纸成功则关闭贴纸选择界面。
- 登录、缓存、联系人表单、媒体库及确认框覆盖打开它们的页面。右滑确认框只取消，不提交操作。

电脑保留左右分栏；对话框、菜单、设置和音频浮层支持相同手势。

`page-gestures.js` 是唯一的手势分发入口。原生 dialog 按实际打开顺序优先；随后是设置、菜单、音频、会话信息、聊天和侧栏子页。同一手势只选定一个接收者；拖动期间出现新弹层时，不关闭新弹层。

`swipe-close.js` 只处理跟手位移、透明度、阈值和回弹。返回动作直接调用各层的关闭函数，不模拟按钮点击。输入区、媒体控件、音频转盘、横向标签和滑杆不接管。双指操作取消返回拖动。每帧只写位移、透明度，尺寸在手势开始时读取一次，并换算 CSS zoom。

路由返回沿用 `navigation.js` 的 History 状态。父页面预览使用原有 DOM，不复制列表；会话、联系人及个人页保留返回位置。新增覆盖层须添加到分发器，不能另装一套父子竞争的滑动监听。
